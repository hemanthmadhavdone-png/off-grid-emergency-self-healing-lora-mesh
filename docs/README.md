# Project Documentation

This directory contains the technical documentation for the **Off-Grid Emergency Messaging Using a Self-Healing ESP32-LoRa Mesh** project. It includes the project report, which describes the problem statement, proposed solution, system design, implementation, and key features of the ESP32–LoRa-based communication network.

The architecture diagram provides a visual overview of the network topology and node configuration, illustrating how multiple ESP32 nodes communicate using LoRa technology. These resources are intended to help readers understand the system architecture, hardware components, and overall project implementation. For firmware and setup instructions, refer to the `firmware/` directory and the main repository README.
